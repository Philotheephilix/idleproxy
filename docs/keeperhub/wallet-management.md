# Wallet Management

Secure wallet integration and management for your blockchain automations.

## Wallet Provider[](https://docs.keeperhub.com/wallet-management#wallet-provider)

-   [Turnkey](https://docs.keeperhub.com/wallet-management/turnkey) — Secure enclave wallets with private key export. The default wallet provider in KeeperHub.

## Smart Accounts[](https://docs.keeperhub.com/wallet-management#smart-accounts)

-   [Safe Smart Accounts](https://docs.keeperhub.com/wallet-management/safe) — Deploy a Safe per chain, scope workflow writes with Zodiac Roles allowances, and withdraw funds directly from the Safe.

## Other[](https://docs.keeperhub.com/wallet-management#other)

-   [Gas Management](https://docs.keeperhub.com/wallet-management/gas) — Gas estimation, optimization, and funding
-   [Address Book](https://docs.keeperhub.com/wallet-management/address-book) — Save and manage frequently used addresses
